Hubungkan perangkat ini

Di komputer tempat Prototyper berjalan, klik ikon HP di bawah sidebar (atau palet perintah → Hubungkan HP). Pindai QR-nya, atau ketik kode 6 digit di sini.

Hubungkan HP

Berkomentar, menjawab pertanyaan agent, dan menjalankan agent dari HP lewat jaringan yang sama.

Perangkat terpasang

HP yang terpasang bisa menjalankan agent di komputer ini; pakai hanya di jaringan yang Anda percayai. Hapus/daftarkan prototype, manifest, update, dan mematikan Prototyper tetap hanya dari komputer.

Daftarkan prototype

Arahkan ke folder prototype. Bila belum ada prototyper.json, isinya dideteksi otomatis.

Jenis

    Placeholder {port} dan {host} pada command.run diganti otomatis saat dijalankan.

    Perintah pada run/install akan dieksekusi di komputer ini — pastikan isinya benar.

    Buat prototype baru

    Folder dibuat dari template, lengkap dengan prototyper.json dan AGENTS.md, lalu langsung didaftarkan.

    Agent lokal

    Agent coding yang dikenali Prototyper di komputer ini. Agent yang tersedia bisa dipilih untuk mengerjakan komentar.

    Baru menginstal agent? Klik Cek ulang. Path bisa dipaksa lewat env PROTOTYPER_AGENT_BIN_<ID>, default lewat PROTOTYPER_AGENT_DEFAULT.
